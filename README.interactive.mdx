## The machine

MARK-I is a complete neural runtime: array engine, perceptron, multilayer
perceptron with backprop, convolutional nets, batch normalization, and
multi-head attention — every line hand-rolled, every claim backed by a
`pragma Assert` that actually ran.

## Multi-head attention, hand-rolled

Scaled dot-product self-attention with learned $W_q, W_k, W_v$ per head and a
learned output projection $W_o$. Semantic scores via $Q \cdot K / \sqrt{d_k}$,
max-subtracted stable softmax, full backprop through every projection.

Token-routing training (permutation targets, identity value path so only the
scores must learn): **max error 8.9e-16** after 1500 epochs at `eta = 0.1`.
Numeric gradient checks on `dWq` / `dWo` / `dX` agree to ~1e-10.
